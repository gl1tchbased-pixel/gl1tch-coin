> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove every stale or conceptual value that the site presents as live or real.

**Architecture:** Small, independent fixes. Each comes with a pure helper or a content change and its vitest test. There are no UI-system changes; those are Faz 1.

**Tech Stack:** Next.js 16 (App Router), TypeScript, CSS Modules, vitest (`src/**/*.test.ts`, node env).

**Spec:** `docs/superpowers/specs/2026-10-19-gl1tch-v2-site-design.md` (§4 K5–K7, §10 Faz 0)

## Global Constraints

- Site copy stays English, in the brand's dry, honest voice. Never claim the founder holds tokens; the deployer's full exit on 2026-08-20 is disclosed.
- CURBy stale threshold: **24 h** (`CURBY_STALE_MS = 86_400_000`). Stale shows "Last round · <date> · source paused" with the dot off. Reward draws never fall back to drand.
- `/dashboard` → `/network`, `permanent: true` (308).
- `--text-muted: rgba(245, 247, 248, 0.62)`; `--text-faint: rgba(245, 247, 248, 0.5)`.
- Read `node_modules/next/dist/docs/` before touching Next config (AGENTS.md).
- Branch `feat/v2-faz-0`. Commit, push and deploy only on the founder's word.

## Review Focus

- CURBy timestamp missing or unparseable → treat as stale, never as live (Task 1 test).
- A timestamp a few seconds in the future (clock skew) → not stale (Task 1 test).
- `/dashboard?x=1` or `/dashboard/` → still lands on `/network` (Task 4 check).
- The homepage tokenomics must not print any "Team N%" anywhere, including tooltips and aria (Task 3 test).
- No source file keeps "four pillars" or "Four components" after the count fix (Task 2 test).
