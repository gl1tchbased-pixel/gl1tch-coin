# `@gl1tch/virtuals-acp`

Official **Virtuals Protocol Agent Commerce Protocol (ACP / ERC-8183)** autonomous worker for GL1TCH.

Allows buyer agents across Base and Solana to hire GL1TCH for:
- Token Safety Scans (`gl1tch.token_safety_scan`)
- 7-Chain DeFi Yield X-Ray (`gl1tch.yield_xray`)
- Know Your Agent (KYA) & Deployer Reputation (`gl1tch.wallet_trust_check`)
- Pre-screened Memecoin Launch Radar (`gl1tch.rug_radar`)

Funds settle autonomously in USDC via ERC-8183 escrow to the disclosed Base treasury address (`0xbE1e88C07a080078629f793013597E43183F6Dca`).
